# WaveGen - 硬件时序图可视化设计与波形生成器用户指南 (User Guide)

WaveGen 是一款专为数字集成电路（IC）、FPGA、嵌入式硬件与通信协议工程师打造的**现代化时序波形可视化设计工具**。它完全兼容标准 [WaveDrom](https://wavedrom.com/) 规范，提供纯图形化所见即所得的时序矩阵编辑、丰富的跨拍约束连线标注、多时钟域时基对齐计算以及论文级矢量排版导出能力。

## 1. 快速上手 (Quick Start)

### 本地桌面客户端安装 (Windows / macOS)
本项目支持基于 Electron 打包为独立的本地桌面客户端：
1. 前往 GitHub 仓库的 **Releases** 或 **Actions** 页面。
2. 下载最新版本安装包（如 `WaveGen Setup 1.0.1.exe`）。
3. 运行安装程序完成安装，桌面端享受离线文件读写与独立窗口工作流。

或者直接下载仓库中的app目录中的压缩包至本地解压缩后安装，注意由于windows保护在安装前需要右键安装包选择属性，勾选解除锁定后进行安装。

### 本地源码开发构建
```bash
# 1. 克隆代码仓库
git clone https://github.com/your-repo/WaveGen.git
cd WaveGen

# 2. 安装项目依赖
npm install

# 3. 启动本地开发服务 (支持 HMR 热更新)
npm run dev

# 4. 生产环境构建
npm run build

# 5. 打包本地 Windows 桌面安装包 (Electron)
npm run package:win
```

## 2. 界面工作区概览 (Workspace Layout)

WaveGen 采用直观的双栏/单栏弹性布局：

```
+-----------------------------------------------------------------------------------+
|  WaveGen 顶栏：新建工程 | 模板库 | 撤销/重做 | 缩放 | 导入/导出 | 主题 | 语言 | 视图切换   |
+---------------------------------------------------+-------------------------------+
|                                                   |  波形预览区 (Waveform Preview)  |
|  信号时序矩阵编辑器 (Signal Timing Matrix)           |  - 实时 SVG 渲染               |
|  - 信号卡片列表 (名称、时钟类型、总线数据)            |  - 皮肤切换、刻度比例、对齐虚线   |
|  - 交互式时序方块网格 (Click/Drag 快速编辑)           +-------------------------------+
|  - 周期插入/删除、流水线打拍 (+1D)                   |  时序连线标注 (Edge Editor)   |
|  - 阶段说明轨、智能折叠                             |  - 跨拍箭头、建立/保持时间约束  |
+---------------------------------------------------+-------------------------------+
```

### 全局工具栏 (Header Bar)
- **工程操作**：新建空白工程、标准硬件总线模板（SPI, I2C, UART, AXI, APB 等）、保存/另存工程。
- **历史记录**：随时点击「撤销（Ctrl+Z）」或「重做（Ctrl+Y）」。
- **导入/导出**：一键导出 **SVG 矢量图**（插入 Word / LaTeX）、**高清 PNG**、以及 **标准 WaveDrom JSON**。
- **视图切换**：提供 **左右分屏 (Split)** 和 **上下堆叠 (Stacked)** 模式，分栏比例可随时通过鼠标拖拽或快速预设（35% / 50% / 60% / 70%）进行切换。
- **外观与语言**：支持浅色/深色主题、中英文即时切换。

### 信号时序矩阵区 (Signal Matrix)
左侧（或上方）为时序数据源编辑区。每一行对应一条信号，列对应各个时钟周期（T0, T1, T2...）。在方格中可直接查看并编辑当前周期的波形状态与数据。

### 波形实时预览区 (Waveform Preview)
右侧（或下方）为实时渲染的硬件时序图。任何在矩阵上的改动均以毫秒级即时反映在预览图中。支持滚轮缩放、标尺对齐、多套 WaveDrom 主题皮肤切换。

### 跨拍连线与时序约束编辑器 (Edge Editor)
用于在不同信号、不同周期的节点坐标之间绘制**时序因果箭头**（如时钟触发数据输出）、**建立/保持时间约束区间**（$t_{su}$ / $t_{hold}$）及任意长度的工程文字说明。

## 3. 核心波形绘制与矩阵操作 (Waveform Editing)

### 时序电平符号速查表

WaveGen 严格遵循 WaveDrom 渲染标准，支持所有标准电平与硬件特殊符号：

| 符号 | 信号类型 | 视觉渲染效果说明 |
| :---: | :--- | :--- |
| **`p`** | 上升沿时钟 (Pos-edge) | 带有上升沿箭头标识的完整周期时钟方波 |
| **`P`** | 加粗上升沿时钟 | 强化高亮上升沿的时钟脉冲方波 |
| **`n`** | 下降沿时钟 (Neg-edge) | 带有下降沿箭头标识的完整周期时钟方波 |
| **`N`** | 加粗下降沿时钟 | 强化高亮下降沿的时钟脉冲方波 |
| **`0`** | 低电平 (Low) | 标准低电平逻辑线 |
| **`1`** | 高电平 (High) | 标准高电平逻辑线 |
| **`=`** | 数据总线 (Data Bus) | 带有交叉过渡斜坡的双轨总线，内部可显示字符标签 |
| **`2` ~ `9`** | 彩色总线 (Colored Bus) | WaveDrom 调色盘不同色彩的数据总线块 |
| **`x`** | 不定态 / 冲突 (Undefined) | 内部填充 45° 交叉阴影网格的未初始化/高频跳变状态 |
| **`z`** | 高阻态 (High-Z) | 居中细虚线，代表三态门断开或总线悬空 |
| **`u`** | 弱上拉 (Pull-Up) | 顶部细线，代表总线上拉状态 |
| **`d`** | 弱下拉 (Pull-Down) | 底部细线，代表总线下拉状态 |
| **`h`** | 垂直高电平 (Square High) | **无斜坡过渡**的垂直方波高电平（适合多时钟域严格对齐） |
| **`l`** | 垂直低电平 (Square Low) | **无斜坡过渡**的垂直方波低电平（适合多时钟域严格对齐） |
| **`.`** | 保持电平 (Continue) | 延续上一拍的电平状态（波形不发生跳变） |
| **`\|`** | 波形截断虚线 (Break) | 绘制锯齿折断虚线，代表省略了较长的空闲时钟周期 |

### 电平输入与交互技巧
1. **单击方块**：在常用电平（0 ➔ 1 ➔ = ➔ x ➔ z）之间循环切换。
2. **右键方块 / 点击右侧调色盘**：弹出符号选取板，一键点击所需符号。
3. **双击或聚焦快捷键输入**：可以直接在卡片波形输入框中按键盘键入整段字符串（例如直接粘贴 `p.......` 或 `01.10==x`）。

### 连续拖拽画笔 (Brush Tool)
当需要连续绘制多个相同电平时：
- 在信号矩阵上方的工具栏中选中一种电平（例如 `1`、`0`、`=` 或时钟 `p`）作为全局画笔。
- 鼠标在矩阵方格上**按住左键直接滑动拖拽**，滑过的单元格将被瞬间涂刷成指定电平，绘制几十拍的长总线只需 1 秒钟。

### 周期管理与流水线打拍 (+1D)
- **插入周期**：悬浮在任意周期交界处点击 `+`，可在指定位置插入新时钟周期。
- **删除周期**：点击列头垃圾桶或在末尾缩减周期数。
- **流水线打拍 (+1D)**：
  - 在硬件设计中，信号经过触发器会产生延时拍数。
  - 点击信号卡片左下角的 **`+1D`** 按钮，系统会自动复制当前信号，并将整条波形**向右推迟 1 拍**（首拍自动补 0），命名自动递增（如 `data` ➔ `data_d1` ➔ `data_d2`），是绘制流水线时序的利器。

### 智能收起静止周期 (Smart Fold Cycles)
当时序图很长、中间包含多拍无变化的静止/等待状态时：
- 点击顶部控制栏的 **「智能收起周期」**。
- 系统自动检测所有信号均无电平跳变的静止时钟区间，自动将其折叠为折断标记，大幅收敛波形宽度，使核心交互时序更聚焦。
- 随时点击折叠方块可展开复原。

### 信号卡片管理
- **重命名**：双击信号名称即可修改（支持中英文、总线位宽如 `addr[15:0]`）。
- **拖拽排序**：鼠标按住信号卡片左侧手柄拖拽，即可上下重新排列信号顺序。
- **信号分组与折叠**：支持将相关信号归类（如 `SPI 控制组`、`时钟与复位组`），可整体折叠或展开。
- **颜色标签**：为关键信号标记红/蓝/绿等不同色彩标签，便于在长列表中快速识别。

## 4. 四种文本标注与时序约束展示 (Text & Annotations)

在数字时序图中，经常需要标明“建立时间 $\ge 2.5\text{ns}$”、“ACK 应答握手”、“空闲/传输/校验阶段”等文字。WaveGen 提供了完善的 4 种长文本标注支持：

### 方式一：跨拍时序连线与箭头长文本 (Edge Arrow)
适用于标注**时序约束**（$t_{su}$, $t_{hold}$, $t_{co}$）以及**事件因果关系**（如“时钟沿采样发起读请求”）：
1. **设置锚点 (Node)**：在起点的信号周期方格中打上一个字母代号（例如在 `clk` 的 T1 周期打 `a`），在终点周期打上另一个代号（例如在 `data` 的 T2 周期打 `b`）。
2. **配置连线规则**：打开下方/右侧的 **时序连线标注 (Edge Editor)**：
   - 起点：`a`，终点：`b`。
   - 箭头类型：
     - `->`：直线单向箭头。
     - `~>`：平滑贝塞尔曲线箭头（最常用，圆润美观）。
     - `-~>` / `~->`：带转折的水平/垂直引导线。
     - `<->` / `<~>`：双向测量箭头（表示周期长度或时间窗口）。
     - `-|>`：垂直转折折线箭头。
   - 文本内容：输入任意长度的文字，例如 `t_setup ≥ 3.2ns` 或 `数据锁存`。
   - 样式定制：支持虚线样式、箭头颜色（蓝/紫/红/灰等）、垂直高度微调偏置。

### 方式二：阶段说明轨 (Phase Text Track)
适用于划分协议的全局状态机阶段（如 `IDLE ➔ ADDR ➔ DATA ➔ CRC ➔ ACK`）：
1. 点击高级工具栏中的 **「添加阶段说明轨」**。
2. 系统将在顶部或指定位置生成一条特殊的阶段总线，并将其波形标记为 `====`。
3. 点击各阶段方格，填入阶段名称（如 `地址传输阶段`、`突发写入阶段`），整条波形上方会以清晰的状态条展示时序阶段划分。

### 方式三：总线数据块文字 (Bus Data Tokens)
适用于标注数据总线、状态码、指令字的具体数值：
1. 将某拍电平设为总线（`=` 或彩色总线 `2`~`9`）。
2. 点击信号卡片上的 **「总线数据」** 按钮，会展开数据输入框。
3. 输入数据数组（例如 `0x3F`, `CMD_WRITE`, `ID_OK`）。
4. 文字会自动居中显示在波形对应总线数据块的中央。

### 方式四：全局标题与底部图注 (Head / Foot Notes)
适用于在整张图表的顶部和底部补充技术文档信息：
1. 点击波形预览栏的 **「标尺与标题配置」**。
2. 在 **`head.text`** 中输入波形图主标题（例如 `SPI Mode 0 传输时序规范`）。
3. 在 **`foot.text`** 中输入参数说明（例如 `注: 1 tick = 10ns; 建立时间需满足 Tsu > 2ns; 负载容抗 15pF`）。

## 5. 高级时钟与排版工具 (Advanced Timing Tools)

### 多时钟域 (CDC) 物理时间对齐与时基计算器
在异步 FIFO、跨时钟域总线等场景中，不同信号的时钟频率各不相同（例如 `CLK_A = 100MHz (10ns)` 与 `CLK_B = 40MHz (25ns)`）：
- 点击工具栏的 **「跨时钟域计算器」**。
- 输入两个时钟的频率或周期。
- 系统自动计算**最小公倍数周期 (LCM)** 和最佳时间划分步长（例如自动推荐 1 tick = 5ns）。
- 一键自动生成两个时钟的同步波形序列及半周期对齐标尺，无需人工拿计算器手算拍数！

### 周期标尺设置 (Timing Ruler Config)
- **标尺位置**：可选择在顶部（head）、底部（foot）或两端同时显示时间刻度。
- **起始编号**：支持从 `0` 或 `1` 开始编号（即从 T0 还是 T1 起步）。
- **标尺步长 (Step)**：默认每 1 拍标字；时序很密时长，可设为每 2 拍、每 4 拍或每 8 拍显示一个数字。
- **双沿半周期标尺 (Tock)**：开启后支持 DDR（双沿传输）模式下的上升/下降沿半拍刻度。

### 字体与排版定制 (Waveform Typography)
WaveGen 专为出版级硬件文档设计，支持分离的字体渲染配置：
- **标题字体**：可选优雅的无衬线或衬线字体。
- **信号名与总线字体**：推荐等宽代码字体（如 *JetBrains Mono*, *Fira Code*, *Courier New*），数字与十六进制对齐更为严谨。
- **字号与字重**：提供细微的尺寸与粗细微调，导出后可直接嵌入 IEEE 论文、技术白皮书或芯片规格书。

### 对齐十字虚线 (Timing Crosshair)
- 点击预览区工具栏的 **「对齐虚线」** 按钮。
- 鼠标在波形图上划过时，将出现一条贯穿所有信号的垂直高亮辅助线，并实时提示当前的周期编号 $T[x]$，方便极速对比多路信号的跳变沿是否严格对齐。

## 6. 导入、导出与工程管理 (Import, Export & Project)

### 工程模板库与快速新建
点击顶部 **「模板」** 按钮，内置多种工业标准接口模板，一键载入即可在其基础上修改：
- **SPI 接口**：Mode 0 / Mode 3 全套时序（SCK, CS_N, MOSI, MISO）。
- **I2C 接口**：起始位 (START)、地址帧、ACK/NACK 应答位与停止位 (STOP)。
- **UART 异步串口**：空闲位、起始位、8位数据、奇偶校验与停止位。
- **AXI4-Stream 握手**：TVALID、TREADY、TDATA、TLAST 经典背压流控时序。
- **APB 总线**：PCLK, PSEL, PENABLE, PWRITE, PADDR, PWDATA 两阶段传输。
- **DDR 存储器时序**：双沿时钟与 DQS 数据选通脉冲。

### WaveDrom JSON 双向导入导出
- **导出 JSON**：点击 **「导出 ➔ WaveDrom JSON」**，自动生成标准 JSON 文本，可直接粘贴到 WaveDrom 官方编辑器、GitHub Markdown（搭配 wavedrom 插件）或各类自动化文档工具中。
- **导入 JSON**：点击 **「导入」**，粘贴任意外部 WaveDrom JSON 代码，WaveGen 会自动解析其 `signal`、`edge`、`head`、`foot` 并反向还原为可视化的矩阵方块供您继续编辑。

### 矢量 SVG 导出与高清 PNG 导出
- **SVG 矢量图导出**：
  - 生成纯矢量格式，文字与波形线条无限放大绝无模糊。
  - 支持直接插入 Microsoft Word、PowerPoint、Typora、LaTeX（通过 `\includesvg`）或 Illustrator 二次排版。
- **高清 PNG 导出**：
  - 提供 1x、2x、3x 超采样高清位图导出，适配 Retina 屏幕展示与即时通讯分享。

## 7. 皮肤与个性化 (Skin & Personalition)

### 界面风格
点击顶部 **「跟随系统」** 按钮，内置常见界面风格：

## 9. 常见问题排查 (FAQ)

#### Q1: 为什么节点标注代号（node）通常只有一个字母？
> **解答**：根据 WaveDrom 官方规范，`node` 字符串中的每一个字符严格与一个时钟周期（时钟 tick）对应。如果在一个周期放多个字母，会被解析器识别为跨越了相邻的几个周期。
> 如果您需要标注长词组或公式，请使用 **[方式一：时序连线标注]**，在箭头规则（`a ~> b`）中附带的文本支持**任意长度的中英文字符串**。

#### Q2: 为什么从 GitHub Actions 下载的新打包程序还是旧版？
> **解答**：
> 1. 请确认在 AI Studio 网页中修改后，已通过右上角菜单执行了 **Export to GitHub**（将最新代码提交到 GitHub 仓库）。
> 2. 检查 GitHub 仓库的 **Actions** 页面，确认 `Build App` 构建流程是否显示为绿色成功状态，且完成时间为几分钟内。
> 3. 从该次构建详情最下方的 **Artifacts** 区域下载安装包（确认版本号如 `1.0.1`），安装前建议彻底退出并卸载旧版程序，防止 Windows 缓存干扰。

#### Q3: 导出的 SVG 插入 Word 或 PPT 后字体变了怎么办？
> **解答**：SVG 默认会调用系统内置字体。若使用了特殊等宽字体（如 *JetBrains Mono*），请确保目标电脑上也安装了该字体；或者在 WaveGen 的「字体与排版定制」中选用常见通用字体（如 Arial、Courier New 或 Consolas）。
